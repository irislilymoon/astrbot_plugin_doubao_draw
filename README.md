# 豆包生图（astrbot_plugin_doubao_draw）

用你自己的豆包账号在网页端生图，不调第三方 API、不做中转。

## 用法

- `/draw 一只橘猫` 直接出图
- `/draw 16:9 赛博朋克城市` 指定比例（1:1 / 3:4 / 4:3 / 16:9 / 9:16 / 2:3）
- 发图或引用图片 + `/draw 改成水彩` → 图生图（最多 3 张参考图）
- 也可以先发图，再单独发 `/draw 改成水彩`（图片暂存 10 分钟；群里建议发图时 @ 机器人或引用图片）
- 转发给豆包时会自动加“请直接生成一张图片”/“请参考我上传的图片…”前缀，避免被当成聊天
- 直接对 AI 说“帮我画只猫”，也会调用（LLM 工具 `doubao_draw`）；可在配置里关闭“AI 识别是否生图”
- “AI 识别是否生图”关闭后，只有 `/draw` 能生图，普通聊天不再自动触发
- “AI 优化提示词”开启后，`/draw` 提交前会先用当前对话模型优化一次提示词（默认关闭，会增加耗时）
- 所有 `/draw` 都在当前豆包会话里继续；只有发 `/new` 才会同时开启新的豆包会话（`/new` 本身仍是机器人的新对话命令）
- `/drawlogin` 取二维码，用豆包 App 扫码（登录态存在 profile 目录，掉线才需要重扫）
- `/drawlogin phone 13800138000` 手机号登录，收到短信后直接回复 6 位验证码（或 `/drawcode 123456`）；登录前会自动勾选隐私协议
- 手机号输错：直接重发 `/drawlogin phone 正确号码`，会自动重置登录弹窗；验证码输错/过期：重发 `/drawcode 正确验证码`，或重发手机号重新收码
- `/drawcancel` 取消当前登录并关闭登录弹窗
- `/drawlogout` 退出登录（只清豆包站点登录态，不会关掉共享浏览器）
- `/drawstatus` 看浏览器、登录态、今日剩余额度
- `/ddprobe` 页面结构探测，豆包改版后用来修选择器

## 抓图方式

不抓 DOM、不做视觉识别：插件在页面内克隆豆包 `/chat/completion` 的 SSE 流，实时解析 `image_ori_raw` 原图地址，一出现就下载并转发；多图会逐张发送。**只转发图片**，豆包的文字回复不会发到 QQ。

## 安全提示（装完先读这段）

> [!WARNING]
> **VNC 默认密码是 `iris`，装好后第一件事就是改掉它。**
>
> 插件拉起的 x11vnc 默认只监听 `127.0.0.1:5900`，noVNC/websockify 与面板内嵌静态页同样默认只监听
> `127.0.0.1`，**默认只有本机能连**。如果你为了用远程面板把 `vnc_bind` 改成 `0.0.0.0`，
> 这三个端口就对网络可达了：**任何人都能敲门**：
>
> **密码还是默认的 `iris` 时，插件会强制只监听 `127.0.0.1`，`vnc_bind` 填 `0.0.0.0` 也不生效。**
> 必须先改密码，监听地址才会按配置放开。这是硬限制，不是提示。
> 5900 和 6080 需要密码，6081 只提供静态页面、不含 VNC 通道；
> 一旦密码被猜到，或者你关掉了密码，对方就能直接操作这个浏览器——
> 里面有你已登录的豆包账号、Cookie 和聊天记录，等同于把账号交出去。
>
> 上线前至少做一项，推荐全做：
>
> 1. **改密码**：插件设置里把 `vnc_password` 改成自己的（默认 `iris` 是公开值，等于没有防护）；
> 2. **只在需要时放开监听**：默认 `vnc_bind=127.0.0.1` 只有本机能连；密码仍是默认 `iris` 时，即使填 `0.0.0.0` 也会被强制按 `127.0.0.1` 处理。改掉密码后，`vnc_bind` 才按配置生效；
> 3. **加 TLS**：对外访问套 HTTPS 反向代理，不要把 6080/6081 直接暴露在公网。
>
> `vnc_password_enabled` 可以关闭密码。**关闭等于把无认证的图形桌面交给整个网络**，
> 只允许在完全隔离的可信内网这么做；关闭后 VNC 调试页顶部会以红字标出“未启用密码”。
>
> 设置页里密码以密码框显示（`secret`），这只是界面遮罩：
> `data/config/astrbot_plugin_doubao_draw_config.json` 里的 `vnc_password` 仍是明文，
> 任何能读到该文件的人都能看到密码，注意文件权限与备份去向。

## VNC 图形调试

插件 WebUI 里有「VNC 调试」页面：

- 已有 Xvfb / x11vnc / noVNC 直接复用
- 缺哪个自动拉起哪个；浏览器窗口也会由兜底任务恢复
- **默认启用 VNC 密码**，密码取 `vnc_password`（默认 `iris`），连接时由 noVNC 弹框输入；改完密码重载插件或点「启动 / 修复 VNC」即可生效
- 关闭 `vnc_password_enabled` 后 x11vnc 以 `-nopw` 启动，VNC 调试页会以红色提示条标出当前处于无密码状态
- 页面内嵌 noVNC（6081 的 CORS 静态服务，自带精简查看器 `pages/vnc/viewer.html`），也可复制直连地址 `http://<host>:6080/vnc.html`
- 内嵌查看器默认满屏 100%，整个远程桌面完整可见、无工具栏；`Ctrl+滚轮`缩放，放大后左键拖动（或滚轮、中键）平移，右下角 `100%` 按钮或 `Esc` 回到满屏
- 插件连接常驻 Chromium 后会把窗口拉满虚拟屏（无窗口管理器时 `--start-maximized` 不生效，会留一块黑边）
- 镜像缺少 `Xvfb` / `x11vnc` / `novnc` / `websockify` 时需要先安装
- Docker 部署需要映射 `6080`（noVNC/websockify）和 `6081`（面板内嵌静态服务）；插件会复用已有服务，缺失时自动启动
- 已经跑着无密码的 x11vnc 时，插件检测到认证方式与配置不一致会重启该进程，避免“设置了密码却仍然裸奔”

## 失败怎么处理

豆包没有给出图片（拒绝、繁忙、只有文字）时，插件只发一条固定的“这次没有生成出图片，请稍后再试。”，不转发豆包原话。

## 配置

| 项 | 说明 |
|---|---|
| default_ratio | 默认比例 |
| enable_llm_tool | AI 识别是否生图，默认开；关闭后只用 `/draw` |
| ai_optimize_prompt | `/draw` 前 AI 优化提示词，默认关 |
| timeout | 单次超时，默认 150 秒 |
| no_image_timeout | 等待首张图超时，默认 60 秒 |
| compress_for_qq | 大图转 JPEG 再发 QQ，默认开 |
| vnc_auto_start | 自动复用/补齐 VNC，默认开 |
| vnc_password_enabled | VNC 连接需要密码，默认开；关闭后 5900/6080 无认证，仅限可信内网 |
| vnc_password | VNC 密码，默认 `iris`，**装好请立刻修改**；设置页以密码框显示，只取前 8 个字符 |
| vnc_bind | VNC 监听地址，默认 `127.0.0.1` 仅本机；远程面板需改成 `0.0.0.0` |
| vnc_public_url | VNC 直连地址（可选） |
| vnc_web_port | noVNC/websockify 端口，默认 6080 |
| vnc_embed_port | 面板内嵌静态端口，默认 6081 |
| vnc_rfb_port | x11vnc 端口，默认 5900 |
| vnc_display | X 显示，默认 :99 |
| cooldown | 单用户冷却，默认 20 秒 |
| daily_limit | 每人每日张数，0 为不限 |
| max_refs | 参考图上限 |
| headless | 默认 true |
| chromium_path | 默认 /usr/bin/chromium |
| profile_dir | 登录态目录，留空用插件数据目录 |
| chat_url | 豆包对话页 |
| browser_watchdog | 浏览器兜底自愈，默认开 |
| watchdog_interval | 兜底检查间隔，默认 30 秒 |

浏览器兜底：每 30 秒检查一次，浏览器窗口被误关、页面全关或 Chromium 卡死时会自动重新拉起并打开豆包页。

## 改版了怎么办

1. `/ddprobe` 看 `img` 数量、`editables`/`textarea` 数量、各选择器命中数；
2. 打开 `dd_selectors.py`，把新的选择器加到对应列表最前面；
3. 重启 AstrBot 或重载插件。

## 注意

- 这是网页自动化，不是官方接口；豆包改版会失效，账号也可能被风控。
- **VNC 端口（5900/6080/6081）不要裸奔在公网**：默认只监听 `127.0.0.1`；改成 `0.0.0.0` 之前必须先换掉默认密码 `iris`。
- 默认 20 秒冷却、每日限额，只适合自己或小群用。
- 2C2G 机器跑 Chromium 偏紧，出现 OOM 就把 `renderer-process-limit` 调小或加 swap。
